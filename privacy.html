Drive파일비교 개인정보처리방침

시행일: 2026년 10월 30일

본 도구는 운영자 본인의 Google Drive와 PC 파일을 비교하기 위한 개인용 도구입니다.

접근하는 데이터와 이용 목적

읽기 전용 Google Drive 권한으로 파일 이름, 크기, 체크섬 등 비교에 필요한 정보를 조회합니다. 필요한 경우 rclone이 파일 내용을 읽을 수 있으며, 데이터는 파일 일치 여부 확인에만 사용합니다.

저장 및 공유

인증 토큰은 사용자 PC의 rclone 설정에 저장됩니다. 비교 결과는 PC 화면에 표시되며, 사용자가 별도로 저장할 수 있습니다. 이 웹사이트나 GitHub 저장소에는 Drive 파일, 인증 토큰 또는 비교 결과를 전송하지 않습니다.

운영자는 Google 사용자 데이터를 판매하거나 광고·AI 모델 학습에 이용하지 않습니다.

접근 철회 및 삭제

Google 계정의 타사 연결 관리에서 앱 접근 권한을 철회할 수 있습니다. PC에 저장된 인증 정보와 결과는 사용자가 직접 삭제할 수 있습니다.

안내 웹사이트

이 사이트는 GitHub Pages로 제공되며 별도의 로그인·분석 기능을 넣지 않았습니다. 호스팅 과정의 데이터 처리는 GitHub 개인정보처리방침을 따릅니다.
